## 重构为单页平铺布局（借鉴 ai.zhanglearning.com）

- 核心改动：将原有的「文件夹导航 + 书签网格」多级点击模式改为**单页平铺布局**——所有文件夹和书签在一个页面上展示，侧边栏仅作为滚动导航锚点，大幅减少点击次数。
- 新增 API 端点 `src/app/api/collections/[id]/all-bookmarks/route.ts`：一次性返回合集中所有文件夹和书签数据，供单页平铺布局使用。
- 新增 `src/components/bookmark/SinglePageView.tsx`：核心组件，在一个页面上展示所有文件夹分区及其书签；支持客户端即时搜索、IntersectionObserver 滚动高亮、书签样式控制（默认/毛玻璃、链接/说明显隐、网格/列表视图）。
- 重写 `src/components/website/sidebar.tsx`：从折叠树改为扁平导航列表，点击滚动到对应区块，当前区块高亮显示；导出 `NavFolderItem` 类型和 `activeSectionId`/`onSectionClick` 属性。
- 重写 `src/components/bookmark/BookmarkCard.tsx`：增强 hover 动画——卡片上浮 + 阴影 + 边框变色 + 图标缩放 + 标题变色，过渡时间 200ms。
- 更新 `src/components/collection/CollectionGrid.tsx`：hover 效果优化，卡片上浮 + 阴影 + 图标缩放。
- 更新 `src/app/page.tsx`：选中合集后使用 `SinglePageView` 替代 `BookmarkGrid`；管理 `navFolders` 和 `activeSectionId` 状态并传给侧边栏。
- 本地 `next build` 类型检查通过；因未配置 DATABASE_URL，静态生成阶段数据库报错（与之前一致）。
