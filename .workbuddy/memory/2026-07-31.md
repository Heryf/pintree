## 修复"无法添加文件夹" + 去掉作者标签
用户部署域名 zbbsnm.icu。两个问题：
1. **无法添加更多文件夹**（点击 New Folder 后没反应）—— 代码无数量限制，根因为运行时静默失败：
   - `src/lib/prisma.ts`：原代码仅 `NODE_ENV !== 'production'` 时缓存 PrismaClient，生产环境每次冷启动 new PrismaClient()，Vercel serverless 下连接数累积耗尽 → POST /api/folders 500。改为所有环境无条件缓存实例。
   - `src/components/folder/CreateFolderDialog.tsx`：原 handleSubmit 失败时只 console.error、无用户提示，任何 API 报错都表现为"点了没反应"。改为用 sonner toast 显示成功/错误；同时修复 parentId 重置 bug（成功后应重置为 "root" 而非 ""）。
2. **左下角作者标签**：`src/components/website/footer.tsx` 删除硬编码的 "Powered by Pintree" 块（logo+链接），保留 copyrightText 与社交链接。
- 注意：项目无 node_modules，无法本地构建验证；需用户重新部署到 Vercel 后测试。若 Prisma 缓存修复后仍失败，toast 会显示具体错误，可能需进一步配置数据库连接池（如 Neon pooled connection）。
